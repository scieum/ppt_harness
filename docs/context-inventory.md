# R0 준비물 확인

## 대상
소단원별 PPT 제작과 피그마 검토 작업을 대상으로 한다.

## 기존 자료
기존 파일은 이동하거나 복사하지 않고 원래 경로를 참조한다.

| 경로 | 용도 | 상태 |
|---|---|---|
| ../AGENTS.md | 제작 흐름·승인·작업 지침 | 확인 |
| ../design.md | 디자인 관찰 기록·제작 기준 | 확인 |
| ../logo(black).png | PPT·피그마 공통 로고 | 확인 |

## 미확보·미확인 자료
- PRD: R1-A에서 사용자가 제공한다. 기존 대화를 임의로 PRD로 확정하지 않는다.
- docs/story-service.md: 없음. R1-A에서 확인·승인 후 작성한다.
- docs/story-work.md: 없음. R1-B에서 실제 수작업 경험을 확인·승인 후 작성한다.
- textbook-chunjae 및 etc: 위치와 내용은 아직 확인하지 않았다.
- 참고 PPT: 기존 분석 범위는 9개·248장이다. 요청된 11개 중 2개는 미확보다.

## R0 통과 조건
- 등록한 기존 참고 파일의 경로 존재율: 100%
- 등록한 기존 참고 파일의 용도 기재율: 100%
- 미확보·미확인 자료 목록 작성 완료
- 이후 필요한 자료의 확보 조건은 해당 단계 게이트에서 정한다.

## 인터뷰와 최종 반영
- 한 라운드에 3~4개 질문을 진행하며 각 질문에 기본값을 제시한다.
- 라운드별 파일은 사용자 승인 후에만 작성한다.
- R7에서는 AGENTS.md의 오케스트레이션 규칙을 재확인한다.
- 전체 라운드 종료 후 AGENTS.md 보강 초안을 제시하고 승인받는다.
- CLAUDE.md는 생성하지 않는다.
