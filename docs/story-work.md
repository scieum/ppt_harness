# R1-B 실제 작업 흐름

## 사례
가장 최근 제작한 소단원은 「삼투 현상」이다. 제작은 혼자 진행했고, 마지막에 결과물을 천재교육 측에 전달했다.

## 실제 수행 순서
1. 제작자가 교과서와 완자 문제집을 모두 열어 내용을 분석한다.
2. 제작자가 먼저 장표 디자인을 뽑고 목차를 선정한다.
3. 제작자가 천재교육 교과서의 내용으로 동기 유발 자료를 구성한다.
4. 제작자가 각 PART에 필요한 내용을 정리하고 표를 만든다.
5. 제작자가 다른 교과서에서 다루는 내용이 빠졌는지 확인하고 추가한다.
6. 제작자가 과학적 오류를 검토한다.
7. 제작자가 최종 결과물을 천재교육 측에 전달한다.

## 산출물 명사

| 산출물 | 확인 범위 |
|---|---|
| 내용 분석 결과 | 분석 행동은 확인됨. 별도 파일 여부는 미확인 |
| 장표 디자인 | 목차 선정 전에 작업 |
| 목차 | 장표 디자인 다음에 선정 |
| 동기 유발 자료 | 천재교육 교과서 내용 사용 |
| PART별 내용·표 | 본문 구성에 사용 |
| 누락 내용 보완 결과 | 다른 교과서와 비교해 추가 |
| 최종 결과물 | 천재교육 측에 전달. 구체적인 전달 형식은 미확인 |

## 멈칫한 지점과 게이트 후보

확인된 고민은 “교육과정에 위배되는 내용은 아닌가?”이다. 실제 순서 중 정확히 어느 시점에 고민했는지는 미확인이다.

- 게이트 후보: 교육과정 범위 적합성 확인
- 판정 기록 제안: 포함할 내용마다 관련 성취기준과 근거를 연결하고, 범위 적합성을 판단하지 못한 항목 수를 센다.
- 미판정 항목을 어떻게 처리할지와 통과 기준은 이후 라운드에서 확정한다.
- 현재 기록만으로 범위 밖 내용의 전면 금지나 허용 기준을 단정하지 않는다.

## 넘김과 에이전트 경계 후보

- 내부 작업은 모두 제작자가 직접 수행했다.
- 중간에 다른 사람에게 작업을 넘긴 경계는 확인되지 않았다.
- 확인된 외부 전달은 최종 결과물을 천재교육 측에 넘긴 지점이다.
- 이 전달은 실제 경험의 기록이며, 향후 하네스의 외부 전송을 승인한 것으로 취급하지 않는다.
- 내부 에이전트 분리는 이후 설계할 사항이다. 기존에 역할 분담이 있었던 것처럼 기록하지 않는다.

## R1-A와의 구분
R1-A의 금지 조건은 향후 판정 기준으로 유지한다. 이번 실제 작업 순서에 계획 승인이나 피그마 검토를 소급해 추가하지 않는다.
