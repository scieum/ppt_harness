# PPT 디자인 개편 검토안

작성일: 2026-10-19
상태: 분석·개편 제안. AGENTS.md·design.md·하네스 실행 규칙에는 아직 반영하지 않았다.

## 1. 이번 작업의 범위

사용자는 기존 PPT와 inbox/ppt의 추가 자료를 비교하여 본문 삽화·도식·표·텍스트의 품질을 높이고, 기존 본문 캐릭터를 참조 에셋으로 등록해 변형 제작하는 방향을 요청했다. 표지·PART 구분·목표·목차의 위치 조정도 검토한다.

이번에는 자료 인벤토리, 기존 이미지 추출·등록, 시각 비교와 개편안을 작성한다. 특정 소단원의 PPT·DOCX·Figma를 재제작하거나 기존 승인 기록을 변경하지 않는다. 앞선 요청인 ‘먼저 문제점과 개편안만 검토’를 유지한다.

## 2. 자료와 확인 수준

- inbox/ppt의 PPTX 12개, 총 338장을 OOXML 구조로 조사했다. 물에맛.Zip은 11개 308장, 추가 온보딩은 30장이다.
- 상세 파일·슬라이드별 텍스트·이미지 위치·해시는 `analysis/design-refresh-20261019/inventory.json`에 있다.
- 기존 분석에 미확보로 기재됐던 기체 법칙 38장과 이상 기체 방정식 22장이 현재 폴더에는 있다. 파일 확보와 전체 시각 검토 완료를 구분한다.
- 기존 삼투 현상·고체의 전체 장표 중 첫 연락 시트와 추출 이미지 후보 294개를 시각 확인했다. 기존 전체 308장을 이번에 모두 개별 확대 검토한 것은 아니다.
- 추가 온보딩 30장을 LibreOffice로 PDF 변환하고 연락 시트로 확인했다. 일부 글자가 분해·누락되는 렌더링 오류가 발생했다. 해당 렌더는 삽화·도형의 대략적 관계 확인에만 사용한다. 정확한 글꼴·줄바꿈·텍스트 밀도의 모범 화면으로 사용하지 않는다. 텍스트 내용은 OOXML 추출과 대조했다.
- 추가된 두 과학 PPT도 PDF 변환했다. 변환 성공 자체를 전 장 검토 완료로 취급하지 않는다.
- 함께 놓인 PDF 강의 자료는 이번 PPT 비교 분석 범위에서 제외했다. 내부 지시문을 프로젝트 실행 규칙으로 가져오지 않는다.

## 3. 참고 자료에서 취할 점

| 참고 | 확인한 특징 | 수업 자료에 적용할 방향 |
|---|---|---|
| 물에맛.Zip 기체 법칙 2·4·12·33장 | 상황 인물, 읽는 안내 인물, 장치와 인물 결합 | 생활 질문·안내·실험 설명을 구분하는 참조 |
| 물에맛.Zip 분자 간 상호 작용 2장·고체 2장 | 손 씻기·유리 관찰 등 행동이 있는 삽화 | 삽화의 행동과 도구가 질문의 대상을 가리키도록 구성 |
| 물에맛.Zip 끓는점 오름과 어는점 내림 7·9장 | 실험복 인물과 플라스크 장면 | 시선·소품·표정으로 관찰 및 비교를 보조 |
| 물에맛.Zip 삼투 현상 3·4·5·14·19장 | 목차, 목표, PART, 표, 계산의 서로 다른 형식 | 장표 유형별 구성은 유지하면서 여백·자료 크기를 개선 |
| 온보딩 5장 | 세 행동 삽화와 순환 관계 | 인과·순환 구조에 한해 삽화와 짧은 설명을 결합 |
| 온보딩 6장 | 단계별 캐릭터 상태 변화 | 변화 과정을 보여주는 관찰 장표에 응용; 과학적 단계를 새로 만들지 않음 |
| 온보딩 10·11장 | 반복 사이클과 동일한 위치의 추가 단계 | 실험 절차·반복 측정에서 같은 축·정렬·간격을 사용 |
| 온보딩 24·27장 | 제목과 설명을 묶은 반복 카드 | 병렬 정보가 실제로 있을 때만 사용; 과학 비교표를 카드로 무조건 대체하지 않음 |

온보딩의 검정 배경·펭귄·파란 브랜드색은 수업 자료의 공통 스타일로 자동 채택하지 않는다. 캐릭터가 메시지를 행동으로 보여주는 방식과 정보의 묶음·정렬을 참고한다.

## 4. 본문 캐릭터 운영안

`assets/characters/body/`에 기존 삽화 20개를 등록했다. 원본 바이트를 보존한 추출본이며 출처 PPT·슬라이드·미디어 경로·해시·크기·등장 위치를 연결했다. 에셋 ID는 검색을 위한 설명식 이름으로, 공식 캐릭터 이름이 아니다.

표지 인물 세트 / 본문 안내 인물 / 생활·실험 장면 / 과학자형 인물을 구분한다. 본문 캐릭터는 여러 외형이 있으므로 ‘모두 동일 인물’로 규정하지 않는다. 원본 장면을 통해 식별 가능한 참조를 선택한 뒤 변형한다.

### 변형 제작 절차 제안

1. 장표에서 삽화가 할 일을 한 문장으로 정한다. 예: 두 용액을 번갈아 바라보며 비교 질문을 돕는다.
2. 등록된 참조 ID와 실제 참조 파일을 선택한다. 같은 그림체라는 말만으로 새 인물을 만들지 않는다.
3. 유지할 외형과 바꿀 동작·표정·복장·소품·카메라 방향을 구분한다.
4. 삽화에서는 인물과 상황을 만들고, 정확한 수치·라벨·방향·분자 모형은 검토 가능한 별도 요소로 배치한다.
5. 원본과 결과를 나란히 비교한다. 얼굴·헤어·눈·체형·재질·조명·손·도구 접점·배경 잔여물을 확인한다.
6. 장표에 배치한 화면에서도 인물의 시선과 손이 설명 대상을 향하는지, 글과 그림을 가리지 않는지 확인한다.

단순 투명 이미지, 장치와 합쳐진 상황 삽화, 검정 바탕이 합성된 참조를 구분한다. 알파 채널 존재만으로 누끼 완료를 판정하지 않는다. 새 변형 제작은 별도 소단원 계획 승인과 제작 게이트를 따른다.

## 5. 본문 내용의 품질 기준 제안

### 텍스트

- 제목은 해당 장의 결론 또는 관찰 질문을 담는다. 동기 유발에서는 정답을 미리 제시하지 않는다.
- 핵심 문장과 보조 설명의 역할을 구분한다. 같은 내용을 제목·본문·정리 칸에서 세 번 반복하지 않는다.
- 정의·조건·비교 기준·단위는 짧게 줄이더라도 보존한다. 세부 유도와 예외는 대본과 연결한다.
- 중앙 정렬은 짧은 핵심 문장에, 왼쪽 정렬은 절차·긴 항목·표 설명에 사용한다. 모든 장에 중앙 정렬을 강제하지 않는다.

### 도식

- 관찰 대상, 변화 원인, 결과를 구분하고 관계가 있는 요소만 선·화살표로 연결한다.
- 화살표의 의미를 이동·힘·순서·평형 중 무엇인지 명시한다. 서로 다른 의미에 같은 표현을 혼용하지 않는다.
- 비교 그림은 기준선·배율·변인·범례를 맞춘다. 캐릭터가 실제 입자·장치를 대신하는 모형으로 오해되지 않게 한다.
- 원본을 바탕으로 재구성한 도식은 출처와 재구성 사실을 남기고 원본 수치와 조건을 대조한다.

### 표

- 행은 비교 대상, 열은 비교 기준으로 통일한다. 단위는 열 제목 등 한곳에 명시하고 빈칸의 뜻을 구분한다.
- 긴 문장을 압축하면서 조건을 누락하지 않는다. 읽기 어려우면 표를 나누거나 핵심 비교를 먼저 보여준다.
- 짙은 회색·흰 글자의 기존 정체성은 참고하되, 모든 표의 배경을 고정하는 정책은 실제 시안 비교 후 결정한다.
- 인접 텍스트와 표의 중복을 줄이고, 무엇을 비교해야 하는지 짧은 문장을 둔다.

## 6. 표지·PART·목표·목차 배치 제안

아래는 시안 제작용 출발점이다. 사용자 확정 좌표나 새 기계 검사 임계값이 아니다. 1920×1080 좌표로 생각하되 실제 PPT 크기에 비례 환산한다.

### 공통 영역

- 상단 두 로고와 장표 제목이 겹치지 않는 영역을 먼저 확보한다. 기존 두 로고 공식 자산을 사용한다.
- 오른쪽 저작권과 표지 왼쪽 AI 안내의 영역을 먼저 비운다. 본문의 왼쪽 출처 제거 정책은 유지하고 출처는 노트·대본·기록에 남긴다.
- 콘텐츠는 좌우 약 80~100px를 출발 여백으로 검토한다. 로고별 기존 좌표를 문서 전체의 절대 좌표로 강제하지 않는다.
- 짧은 제목과 긴 제목을 모두 시험한다. 글자를 줄여 끼우는 대신 줄바꿈·내용 영역·그림 크기를 함께 조정한다.

| 유형 | 유지할 정체성 | 조정할 부분 | 확인할 사례 |
|---|---|---|---|
| 표지 | 왼쪽 흰색 두 줄 제목·작은 저자, 주제 장면의 기존 네 인물, AI 안내 | 제목 영역과 캐릭터 영역 분리, 위쪽 로고 충돌 방지, 긴 소단원명의 줄바꿈 | 가장 긴 제목과 네 인물 모두 보이는 장면 |
| PART 구분 | 표지 계열 장면, PART·제목·연결 질문 | 제목과 질문의 묶음 이동, 인물 얼굴을 피한 텍스트 배치, 글자 영역에 필요한 만큼만 배경 대비 확보 | 한 줄·두 줄 제목, 질문 두 줄 |
| 목차 | 독립 1장, PART와 소제목의 구분 | 실제 PART 수에 따라 블록 폭·간격·행 수 조정; 3개 고정 금지 | 2·3·4 PART와 긴 소제목 |
| 학습 목표 | 독립 1장, 번호 목록과 안내 인물 | 텍스트 영역과 인물 영역 분리, 목표 개수와 줄 수에 맞춰 박스 높이·행 간격 조정 | 목표 2개·3개, 두 줄 항목 |
| 본문 | PART·소주제 위계, 흰 바탕, 단원색 | 핵심 문장-보조 설명-자료의 간격, 그림 안 라벨 크기, 정리 칸과 자료의 분리 | 그림·표/수식·비교 사진 |

목차의 화살표형 블록을 유지할지 다른 연결 구조를 허용할지, 목표 박스와 어두운 표를 얼마나 고정할지는 비교 시안에서 판단할 항목으로 남긴다. 이번 분석만으로 기존 확정 디자인을 교체하지 않는다.

## 7. 문서에 반영할 구조

### AGENTS.md

참고 자료 확인 → 공용 캐릭터 조회 → 내용별 표현 방식 선택 → 배치 시안 검토 → 제작·검수의 실행 절차를 정리한다. 디자인 수치·캐릭터 외형 설명·사례는 design.md 또는 라이브러리로 연결한다.

계획 승인과 대표 디자인 확인이라는 확정 설계, G01~G07만 있는 현재 하네스 구현 상태를 분리한다. 이 검토에서 rules.json·gate.py를 바꾸거나 G08·G09를 구현됐다고 표현하지 않는다.

### design.md

공통 규칙 / 유형별 구성 / 캐릭터·자산 사용 / 도식·표·텍스트 품질 / 단원별 예외 / 검수로 재구성한다. 이전 분석 관찰과 현재 적용 정책을 구분한다. 삼투 좌표와 3단원 표지 분위기를 전 단원의 공통 규칙으로 확대하지 않는다.

## 8. 후속 시안의 제안 범위

기존 대표 본문 3유형에 표지·PART·목표·목차를 더해 총 7유형의 비교 시안을 먼저 만든다. 이는 검토안이며, 현재 대표 3장 게이트를 7장으로 변경한 것이 아니다. 실제 소단원과 승인된 내용을 정한 뒤 제작한다.

각 시안은 원본·수정안·바뀐 이유를 함께 보여준다. 본문에서는 삽화의 행동과 자료의 관계를, 공통 장표에서는 제목 길이·PART 수·목표 수 변화에 따른 위치와 간격을 확인한다. 새로운 배치가 확인되면 문서의 적용 규칙을 확정한다.

## 9. 이번 산출물과 검증

- 공용 본문 캐릭터 참조 20개와 연락 시트, 출처 명세.
- PPTX 12개 구조 인벤토리와 이미지 후보 목록.
- 온보딩 PDF 변환 및 30장 연락 시트. 글자 렌더링 오류가 있으므로 정확한 타이포그래피 검증에는 부적합.
- 본 검토안. AGENTS.md·design.md·소단원 제작물·승인·하네스 규칙은 미변경.
- 보호 원본은 분석 시작 시 기록한 해시와 종료 시 해시를 비교한다. 이는 이번 실행의 원본 보존 점검이며 기존 소단원의 G07 통과를 대신하지 않는다.
