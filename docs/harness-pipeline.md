# R3 하네스 파이프라인

> 2026-10-19 사용자 정정 후 실행 기준: [엄격한 레퍼런스 검증 1.1.0](harness-reference-fidelity.md). 아래의 대표 3장·승인 1회·G08/G09 미구현 설명은 당시 설계 이력이며 현재 실행에는 적용하지 않는다. 현재는 7유형·두 확인 지점과 rules.json 1.1.0을 따른다.

## 단계와 입출력

| 단계 | 입력 | 출력 |
|---|---|---|
| ① 근거 분석 | 소단원·성취기준·교과서·완자 | 출처 목록·내용 비교·교육과정 범위 판정 |
| ② 페이지 계획 | 분석 결과·디자인 기준 | 페이지별 plan.md |
| ③ 이미지 준비 | 승인된 계획·원본 그림·캐릭터·로고 | 표지·삽화·교과서 크롭·자산 목록 |
| ④ PPT·대본 제작 | 승인된 계획·이미지 자산 | PPTX·DOCX·발표자 노트 |
| ⑤ 검수·피그마 반영 | 제작물·판정 기준 | 검수 기록·피그마 시안·수정된 최종본 |

## 순서와 승인
① → ② → 사용자 계획 승인 → ③ → ④ → ⑤ 순서로 진행한다.

계획 승인 전에는 ③과 ④를 시작하지 않는다. 계획 승인과 피그마 최종 검토의 관계는 R5에서 확정한다.

## 교육과정 범위 판정
①에서 포함 후보 내용마다 다음 상태 중 하나를 기록한다.

- 범위 내
- 보충·심화
- 제외
- 미판정

미판정 항목이 1건 이상이면 ②의 계획 확정을 막는다. 사용자 설명이나 추가 근거로 미판정을 해소한 뒤 진행한다.

‘보충·심화’의 포함 조건과 판정 증빙 형식은 후속 라운드에서 확정한다.

## 실패 시 복귀

| 문제 종류 | 복귀 단계 |
|---|---|
| 근거·교육과정 범위 | ① 근거 분석 |
| 페이지 구성 | ② 페이지 계획 |
| 표지·삽화·크롭 | ③ 이미지 준비 |
| 문구·배치·수식·대본 | ④ PPT·대본 제작 |

수정된 단계와 그에 의존하는 후속 단계의 검사를 다시 실행한다. 여러 문제가 함께 있으면 가장 앞선 관련 단계부터 수정한다.

계획이 변경되면 기존 승인 적용 여부를 다시 확인한다. 승인 유지·재승인을 구분하는 구체적인 기준은 R5에서 확정한다.

## 후속 확정 사항
- R4: 파일명, 규칙의 단일 기준 파일, 재개 방식
- R5: 단계별 통과 조건, 승인 증빙, 실패 처리
- R6: 작업 역할과 편집 경계

현재 문서는 파이프라인 설계이며, 판정 스크립트나 작업 에이전트를 구현한 상태는 아니다.
