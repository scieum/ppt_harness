# R2 하네스 목적

## 목적
소단원마다 달라지는 수업 내용을 기존 디자인과 제작 절차에 맞춰 구성하고, 단계별 게이트로 검증해 반복 제작의 일관성을 확보한다.

## 매번 달라지는 입력
- 소단원명
- 교육과정
- 목표 슬라이드 수
- 수업 시간
- 참고 자료 목록

목표 슬라이드 수와 수업 시간이 없으면 제안값으로 표시하고 계획 승인 시 확정한다.

## 고정 기준
- design.md의 디자인 기준
- 제공된 로고
- 교과서 우선순위: 천재교육 물질과 에너지 주 자료, 화학Ⅱ 보조 자료, 다른 교과서·완자 비교 자료
- 제작 전 계획 승인 절차

PART 수, 사용할 그림, 캐릭터 배치와 페이지 구성은 소단원에 맞춰 조정한다.

## 사용자와 범위
- 직접 사용자: 수업 자료 제작자 본인 1명
- 학생: 수업 청중
- 천재교육: 최종 결과물 수령처
- 외부 전달은 자동화 범위에서 제외한다.

## 완료 기준
승인된 계획에 따른 PPTX·DOCX와 피그마 시안이 준비되고, 필수 게이트의 실패·미판정 항목이 각각 0건이며, 사용자 검토 의견의 반영이 끝나면 완료한다.

## 후속 확정 사항
- 필수 게이트와 미판정 처리 방식은 R5에서 정한다.
- 스크립트 검사 통과를 과학적 정확성이나 시각적 품질의 완전한 보증으로 간주하지 않는다.
- 제작 전 계획 승인과 피그마 최종 검토의 관계는 R5에서 정한다.
