# 공통 제작 문서 정리 기록

작성: 2026-10-30

## 요청과 반영

누적 작업을 루트 문서에 정리해 다른 단원에도 적용하도록 요청받았다.

- 루트 plan.md를 특정 3-01 장수·시간 계획에서 공통 제작 절차로 정리했다.
- design.md를 현재 레퍼런스·테마·타이포그래피·패널·배치 기준으로 정리했다.
- asset.md에 원본/생성/구조 재현 구분, 완자 내용 참고와 그림 사용 금지, 등록 캐릭터, 수식 생성·보정·비율·출처 규칙을 모았다.
- qa.md에 내용/화면/레퍼런스/버전 검수와 기존 G10 연결을 정리했다.
- templates/unit-plan.md를 추가하고 AGENTS.md·README.md·brief.md에 진입 경로와 우선순위를 연결했다.
- 이전 루트 plan.md와 design.md는 docs/history/2026-10-30-root-docs/에 원문 보존했다.
- 하네스 안내의 오래된 G01~G09 표기와 외부 패키지 불필요 문구를 실제 G10·Pillow 조건에 맞췄다. 검사 코드는 변경하지 않았다.

## 범위와 검증

공통 문서의 로컬 Markdown 링크가 존재하는지 확인했다. 단원별 계획·보존 장표·PPT·이미지·수식·코드에는 이번 문서 정리로 변경을 가하지 않았다. 기존 작업 트리의 다른 수정은 유지했다. 현재 작업에서 PPT 전체 QA나 새 게이트 실행·통과를 선언하지 않는다.

O/X 캐릭터의 최근 비율 수정처럼 검토 중인 개별 시안은 공통 승인 기준으로 승격하지 않았다. 블랙/화이트를 구분하고 새 단원은 사용자 지정 테마와 참조 원본을 따른다. 단원별 최신 파일·전달·승인 상태는 각 단원의 실제 산출물과 WORKLOG에서 별도로 확인한다.

Git 커밋·푸시는 이번 문서 정리에서 수행하지 않았다. 다음 공유 시 교재·완자·레퍼런스 원본/추출물과 포함 결과물 제외 규칙을 유지한다.

## 후속 요청: 소단원별 관리 문서

루트 템플릿.md·lesson.md·ppt.md를 추가했다. 현재 확인한 3-01/3-02/3-03을 등록하고 기존 단원 계획·작업로그·검토 상태로 연결했다. v48 파일 존재와 v47 검토 상태의 차이, 화이트 v02가 블랙 v42 기반인 점을 명시했다. AGENTS.md에 새 단원/버전 변경 시 함께 갱신하도록 연결했다. PPT 자체나 기존 승인 상태는 변경하지 않았다.
