# R1-A 서비스 맥락

## 근거 문서
- ../AGENTS.md: 제작 흐름, 승인 조건, 자료 사용과 결과물
- ../design.md: 기존 PPT 디자인과 재현 기준

사용자 지정에 따라 두 문서를 PRD 대신 사용한다.

## 서비스 사용자
직접 사용자는 소단원을 제시하고 계획·시안을 검토하는 수업 자료 제작자다. 학생은 수업 자료의 청중이며, 하네스를 직접 사용하는지는 문서에서 확인되지 않는다.

## 유저스토리
1. 수업 자료 제작자가 오늘 제작할 소단원을 제시한다.
2. 수업 자료 제작자가 성취기준과 교과서 비교를 반영한 페이지 구성 계획을 확인하고 승인한다.
3. 수업 자료 제작자가 승인 후 준비된 표지·삽화 이미지를 미리 확인한다.
4. 수업 자료 제작자가 기존 디자인을 계승한 PPT와 상세 발표 대본을 제공받는다.
5. 수업 자료 제작자가 피그마 시안을 검토하고 수정 의견을 전달한다.

## 어기면 안 되는 것

### INV-01. 계획 승인 전에 생성·제작을 시작하지 않는다
근거: AGENTS.md의 ‘계획서 제공과 승인’, ‘승인 후 이미지 우선 준비’.

판정 가능한 조건 제안:
- 이미지 생성·PPT 본 제작 시작 시, 해당 계획 버전에 대한 사용자 승인 기록이 존재해야 한다.
- 승인 기록 없이 시작한 생성·제작 실행 수는 0건이어야 한다.
- 승인 증빙의 형식과 계획 버전 연결 방식은 R4~R5에서 확정한다.

### INV-02. 참고 원본을 변경하지 않는다
근거: AGENTS.md의 ‘작업 폴더와 자료 관리’.

판정 가능한 조건 제안:
- 교과서·참고 PPT·sources/ 등 보호 대상 원본의 내용 변경, 삭제, 이동, 이름 변경은 각각 0건이어야 한다.
- 실행 전후 파일 경로와 내용 해시를 비교한다.
- 동기화로 외부 변경이 감지되면 자동 통과시키지 않고 원인을 구분한다.
- 보호 대상 목록과 검사 시점은 R4~R5에서 확정한다.

## 다음 라운드와의 구분
위 유저스토리는 서비스의 이용 목적이다. 실제 수작업 순서는 R1-B에서 별도로 듣는다. 두 금지 조건은 이후 게이트의 판정 기준으로 사용하며, 실제 작업 경험을 대신하지 않는다.
