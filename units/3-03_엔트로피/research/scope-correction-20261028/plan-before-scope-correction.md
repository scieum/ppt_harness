# 3-03 엔트로피 · PPT 페이지 계획

2026-10-28 · v0.2 · **전체 방향 수정 · 기존 40장/3차시/학습 범위 유지**

천재 중단원 「2. 엔트로피」의 「01 엔트로피」와 「02 반응의 자발성」을 프로젝트의 3-03으로 묶는다. 완자의 대응 단원명은 「화학 변화의 자발성」이다. **40장·150분(50분×3차시) 제안**이며 장수·시간은 사용자 지정값이 아니다. 기존 v0.1은 사용자 “ㅇㅋ 진행”으로 승인받았다. 이번 수정은 사용자가 지정한 3-02 plan.md와 최신 WORKLOG·R04/R05를 반영한 **전개·시각·자산 운용의 전체 수정 계획**이다. 40장·150분·학습 목표·장별 핵심 메시지는 유지한다. 현재 PPT v02는 이전 흰 본문 방향의 검토본이며 이 새 방향의 전체 반영본이 아니다.

## 이번 수정의 기준과 바뀌는 방향

참고한 [3-02 plan.md](../3-02_헤스법칙/plan.md)는 초기40장 설명과 후속50장 기록이 함께 있는 이력 문서다. 최신 [WORKLOG](../3-02_헤스법칙/WORKLOG.md)의 v20 반복 인물 제거, v23 설명 단계 보강, v27~28 투명 생성 반응식, 검정·초록 테마 후속 기록을 함께 읽었다. 옛 ‘본문 흰색’, ‘반응식을 생성에 맡기지 않음’, ‘항상 안내 캐릭터’, 과거42장 번호를 새 지시처럼 복사하지 않는다. **3-02의 계획 방식과 최근 사용자 정정을 3-03 과학 내용에 적용한다.**

### 직접 확인한 레퍼런스 화면과 적용

`R04/R05`는 **라이브러리 PDF ID**이며 기존 표의 `R숫자`(3-01 사용자 수정본 실제 쪽)와 다르다. [채택 기록](research/direction-v02/adoption.md)에 파일·쪽·적용 장을 분리했다.

- R04 PDF12: 질문 제목·짧은 설명·아래 상황 캐릭터, 캐릭터 하단 뒤의 짙은 녹색. →2장. 배경과 캐릭터를 별도 레이어로 두고 얼굴·몸 비율은 바꾸지 않는다.
- R04 PDF14: 전체 특징 먼저 안내하는 짧은 표제 묶음. →16·28장. 세/네 항목 수는 과학 내용에 맞춘다.
- R04 PDF25, R05 PDF29: 왼쪽 번호/표제와 오른쪽 설명의 반복 행. →8·20·21·24·26·27장. 숫자는 실제 읽는 단계가 있을 때만 사용한다.
- R04 PDF33: 무엇/해석/조건을 짝지어 읽는 구조. →15·23·31·32장. 원본의 UI 제작 문구는 수업 화면에 넣지 않는다.
- R05 PDF25·31: 비교 대상과 조건을 같은 높이에 대응, 제한된 초록 강조. →17·19·33·36~38장.
- R05 PDF32: 장식 없는 정돈된 비교표. →19·33·38장. 원본 과학 표와 새 요약표의 출처 종류를 구별한다.

## 수업 목표·범위

대상: 2022 개정 물질과 에너지를 배우는 고등학생. 선수 개념: 상태·입자 모형, 계수와 몰수, 3-01의 발열·흡열 및 반응 엔탈피. 헤스 법칙 계산은 다시 가르치지 않는다.

1. 엔트로피의 의미를 알고 상태·확산·혼합과 간단한 반응의 엔트로피 변화를 정성적으로 설명한다.
2. 계와 주위를 정하고 물질·에너지 교환으로 세 종류의 계를 구별한다.
3. 엔탈피 변화와 계·주위의 엔트로피 변화를 연결하여 자발성을 설명한다.

성취기준 **[12물에03-03] “엔트로피의 의미를 이해하고, 엔탈피와 엔트로피의 변화로 화학 변화의 자발성을 설명할 수 있다.”** 천재 지도서 PDF/인쇄18쪽 전재 문구를 확인했다. 19쪽 해설에 따라 엔트로피는 정성적으로 다루고 깁스 자유 에너지는 제외한다. 이번 확인은 지도서 전재본이며 국가 고시 원문을 별도로 확인한 것으로 표현하지 않는다.

## 디자인과 자산 운용 기준 — v0.2

1. **검정·초록을 본문 주 방향으로 채택한다.** 흰 제목/본문·회색 보조·제한적 연두 강조를 R04/R05 실제 화면과 맞춘다. 짙은 패널은 정의·비교·단계 구분이 필요한 곳에만 쓴다. 구체 색값은 실제 원본 픽셀 확인 후 제작 기록에 남기며, 관찰하지 않은 수치를 원본값이라고 적지 않는다.
2. **기존 시리즈의 구조는 유지한다.** 표지 두 줄 제목·저자·로고, 목차의 깊은 꺾임과 좁은 간격, 학습 목표의 큰 단일 상자·왼쪽 정렬·번호, 본문 Part/소주제 위계를 유지한다. 검정 화면에 목차 블록이 묻히지 않게 원본 윤곽을 보존하고 대비를 검토한다. 표지 현재 장면은 녹색 진하기나 테마 변경을 이유로 임의 재생성하지 않는다.
3. **검정 배경 로고는 화이트 원본만 사용한다.** `units/3-01_엔탈피와열화학반응식/assets/v10-part-sci_eum_logo.png`. 검정 로고 뒤 흰 받침을 붙이지 않는다. T셀파는 표지1장만, 기존 bbox/visible_bbox·비율·색 유지.
4. **캐릭터 뒤 그라데이션은 2장만 기본 후보로 둔다.** 짙은 녹색이 캐릭터 뒤 하단에서 위·가장자리의 검정으로 사라지게 한다. 캐릭터와 별도 레이어로 제작하며 얼굴·비율을 편집하지 않는다. 인물 가장자리 발광·그림자·색 번짐을 넣지 않는다. 그림·표·반응식 장에 같은 배경을 복제하지 않는다.
5. **정의·단계·표·확인을 다른 구성으로 만든다.** 6장 정의는 한 영역. 8/20/24/26/27장은 뜻·순서를 대응하는 행. 16/28장은 전체 목록.19/33/38장은 자료·요약표.12/39/40장은 조건·학생답·해설을 묶은 확인. 단순히 모든 장에 같은 회색 상자3개나 하단 결론 바를 넣지 않는다.
6. **원본 과학 그림·사진의 의미를 보존한다.** 그림Ⅲ-10~17의 색·라벨·상태·방향을 유지하고 필요한 주석만 직접 연결한다. 검정 테마를 이유로 사진이나 그래프 색을 반전하지 않는다. 밝은 원본이 필요한 경우 명확한 자료 판독 영역 안에 두며 그 부분을 투명 그림으로 가장하지 않는다. 캡션은 편집 가능한 문구로 분리한다.
7. **화학 반응식은 최신 생성 정책을 적용한다.**10/12/35~37/39장의 새/재구성 반응식은 원문 검산 후 투명 이미지로 제작한다. 교재 풀이 지면이나 여러 식이 섞인 캡처를 새 본문으로 그대로 붙이지 않는다. 같은 장의 반응식은 비율을 유지하고 실제 글자 크기·글자 사이 간격을 맞춘다. 설명식인 ΔS·ΔE 관계와 일반 표/설명은 Pretendard 편집 가능한 요소로 유지한다.
8. **인물·칠판은 필요한 역할만 둔다.** 2장은 생성 학생 장면,4장은 작은 학생 안내 후보.40장 설명 과제에는 인물 없음. 칠판은13장 소정리1곳만 후보이며 출처는 R03 PDF22 글자 없는 원본(`assets/reference-library/20261027/components/R03-p22-whiteboard-original.png`). 칠판 없이 더 잘 읽히면 제외한다. 밝은 칠판 글자는 충분한 대비를 실제 화면에서 확인한다.
9. **과학자 시트와 학생 본문 역할을 구분한다.** 현재 `assets/scientists/clausius-v02.png`(남색 코트·앉음·회중시계), `boltzmann-v02.png`(초록 조끼·섬·구슬상자)를 보존한다. 클라우지우스 ‘엔트로피 개념 도입’, 볼츠만 ‘통계적 해석’의 배경 설명 후보이며 계산·판정 장표의 장식으로 반복하지 않는다. 현재40장에 별도 역사 장을 추가하지 않는다. 소품은 실제 역사적 소유물·증명 실험으로 설명하지 않는다.
10. **읽는 순서와 공개를 계획한다.**8장은 최종/초기 항→차이의 부호,10장은 계수/모형→분자 수→ΔS,24장은 전체/계/주위→합,26~27장은 열방향→주위변화→부호,29~32장은 계/주위의 부호→크기→판정,36~39장은 조건→학생 예측→해설 순서. 단순 정답색 변경을 클릭 공개라고 기록하지 않는다. 대본은 발화와 가리키기·공개 운영을 분리한다.

## 정확성·검수·진행 조건

원본 T94 표제의 ‘수증기의 승화’는 보존 출처에 기록하되 학생 제목은 ‘수증기가 얼음으로 변할 때’로 명료화한다. 자발성은 빠르다는 의미가 아니다. 계의 ΔS 증가만으로 모든 자발성을 판정하지 않는다. 보온병은 이상화한 모형으로 다룬다. 용해의 ΔS는 모든 물질로 일반화하지 않는다. ΔH와 ΔS의 크기를 직접 비교하지 않고 ΔS계와 ΔS주위를 비교한다. ΔS전체=0의 심화·정량 계산·온도 문턱 유도는 추가하지 않는다.

승인 후 원본별 크롭과 등록 인물을 열어 대조하고 출처·해시를 고정한다. 7유형 대표 시안(표지1,Part5,목표4,목차3,그림10,표/수식33,비교사진36)을 만들고 G08 및 현재 버전에 대한 사용자 디자인 확인 G09 후 전체40장과 상세 대본을 제작한다. PPT·대본·미리보기 실제 페이지와 클릭 공개 순서를 맞춘다. Figma 검토 전 도구 사전검사와 실제 화면 대조를 수행한다. 기존 계획 승인 기록과 G03 결과는 보존한다. 새 디자인 방향에 대한 G08·G09 통과·사용자 디자인 승인은 아직 없다. 레퍼런스 일치 기준이나 허용 오차는 통과 목적으로 바꾸지 않는다.
