# 사용자 추가 요청: 두 과학자 캐릭터
사용자: “엔트로피를 처음 정의한 클라지우스와 통계물리학으로 증명한 볼츠만도 캐릭터시트에서 다른 과학자들처럼 표현햐주면 좋을듯”
본 작업은 별도 신규 캐릭터2종과 캐릭터시트이며 승인된40장의 학습 목표·페이지 핵심 메시지·장수를 바꾸지 않는다. 아직 기존 정의 장표에 역사·연도를 새 학습 내용으로 추가하지 않는다.
기존 과학자 portrait_a/b를 실제로 열어 스타일 참고 입력에 사용했다. 두 원본 캐릭터의 정체성을 새 인물로 재명명하지 않았다.
설명은 클라우지우스 ‘엔트로피 개념 도입’, 볼츠만 ‘엔트로피의 통계적 해석’으로 구분한다.

추가 사용자 지시: 복장·자세·손에 든 물건을 서로 다르게. v02에서 클라우지우스 남색 코트·앉음·회중시계, 볼츠만 초록조끼·서 있음·구슬상자로 변경. 소품은 캐릭터 표현이며 역사적 실제 소유물·실험 장치로 주장하지 않음. v01은 이력으로 보존.
