# 원본 사용과 준비 결정 · 2026-10-28
교과서90~95쪽 원본 페이지·추출 크롭을 실제 화면으로 대조했다. 반응식 계수·전하·아래첨자·상태를 원문과 검산했다. 94쪽 4사례의 고체화·연소·기화·용해 반응식을 따로 확보했다. 원본 글꼴·수치·상태 기호를 유지하고 설명 문구는 Pretendard로 제작한다.
표지: 승인 계획의 방향제 교실 장면은 후보였다. 얼굴 재생성을 피하기 위해 등록된 1-01 표지 네 학생 원본 이미지를 배경으로 그대로 채택한다. 기존 기체 실험 장면을 새 방향제 관찰 장면으로 가장하지 않는다. 표지 제목·핵심 메시지는 같고 단원 학습 내용의 실험 근거로 사용하지 않는다. Part0에서 방향제 사진과 질문을 별도로 제시한다. 이는 승인 목적 안의 원본 자산 교체이며 목표·범위·장수를 바꾸지 않는다.
본문: 안내 인물 body_guide_reading 원본을 2·4·40장에 사용한다. 원본 투명 PNG이며 갈색 안내 인물 의상 그대로 보존한다. 학생 교복 변형을 새로 생성하지 않는다. 1-01 교복 규칙은 새 학생 삽화 제작 시 적용하며 기존 등록 안내 인물을 다른 사람으로 바꾸지 않는다.
26개 추출본의 contact-1~3을 확대해 원본 페이지와 대조했다. 원본 식은 재생성하지 않았다. 관련 설명식의 H 기울임은 실제 시안 렌더 후 별도 확인한다.
