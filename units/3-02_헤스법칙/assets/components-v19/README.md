# 레퍼런스 기반 편집 가능한 텍스트 상자

reference-textboxes.mjs는 기존 제작기의 box/text/rich/chem/C 함수를 주입해 쓰는 재사용 구성이다. 원본 이미지 크롭이 아닌 참조 구조의 네이티브 재현이다.

- pairedRow: R05 PDF29쪽 번호 표제와 설명 행 → 20장
- explanation: R04 PDF33쪽 표제/설명 영역 → 14·29장
- calculation: R05 PDF29쪽 번호와 설명의 짝 → 38장
- checklist: R03 PDF38쪽 확인 칸과 넓은 목록 → 42장
- 36장의 기호/설명 짝, 29장의 관계식 강조 상자는 같은 원칙으로 제작기에 배치.

모두 Pretendard, 흰 본문 바탕, #303030 표제, #F5F5F5 설명, #57962F 또는 #9FFF68 강조. 반응식 원본 이미지를 대체하지 않는다.
