# 헤스 법칙 대표 5장 — 사용자 검토용

사용자 요청: 표지1장, 동기 유발1장, Part1 본문2장, Part2 본문1장. 전체 계획의 1·2·6·8·17장에 대응한다. 후속 사용자 정정으로 표지→동기 유발→수업 목차→학습 목표 순서를 적용한다.

- 1 표지: 원래 등록된 네 캐릭터 원본을 확보한 후 적용한다. 새 생성 표지 이미지는 사용자 거부로 제외했다.
- 2 동기 유발: 높이 차 비유와 원래 등록된 본문 캐릭터. 3-01 재생성 인물을 대체재로 사용하지 않는다.
- 3 Part1 정의: 사용자 수정본8쪽의 설명 행과 선택적 강조.
- 4 Part1 경로: 완자118의 원본 과학 도식 + 사용자 수정본22·33쪽의 직접 해설 구조.
- 5 Part2 계산: 완자119의 원본 반응식 두 줄 + 사용자 수정본28·38쪽의 계산 위계.

본문 글자·도형·계산은 편집 가능하다. 원본 과학 그림·반응식 및 등록 캐릭터는 이미지이다. PowerPoint 앱에서 재생 검증한 결과가 아니라 Artifact Tool의 렌더링 결과이다.

현재 G01/G02/G03 원래 결과는 미통과다. 이번 대표5장에 대한 명시적 사용자 지시를 제한된 제작 범위의 우선 지시로 기록했다. 전체40장 승인·7유형 승인·G08/G09·전체 제작·최종 완료로 해석하지 않는다.

표지 생성 시도는 기본 image_gen 도구를 사용했으나 사용자가 변형을 지적하여 실제 PPT에서 제외했다. 해당 시도의 파일과 프롬프트는 build/에 이력으로만 보존한다. 최종 검토본은 등록된 원본 캐릭터 이미지를 사용해야 한다.
