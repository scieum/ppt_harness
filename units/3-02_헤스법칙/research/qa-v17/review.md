# 헤스 법칙 v17 · 전체 42장 검수

사용자가 요청한 캐릭터 순환, 레퍼런스 추가와 현재 PPT의 수정·검수를 반영했다. 장수와 학습 내용은 유지했다.

## 반영한 내용

- 등록된 네 인물을 각각 직접 참조한 수업용 포즈를 준비했다. 목표·조건 설명·기준 확인·되돌아보기 등 12장에 안내·생각·설명·확인 역할을 배치했다. 기존 2장과 18장의 특정 장면, 표지와 네 Part 배경은 유지했다.
- 여섯 PDF, 총 474쪽을 레퍼런스 라이브러리에 추가했다. 전체 축소 화면을 살피고 채택한 쪽을 확대해 확인했다. 말풍선과 꼬리, 자료에 붙이는 주석, 비교 항목의 정렬을 적용했다. 외부 자료의 캐릭터·로고·소프트웨어 화면을 화학 수업에 넣지 않았다.
- 큰 계산·그래프·자료표에서는 글자를 줄여 장식 인물을 넣지 않고, 과학 자료가 읽히는 크기를 유지했다.

## 검수 결과

- 전체 42장을 렌더링해 수정 전후 화면을 대조했다. 변경 장표는 개별 확대 화면도 확인했다.
- PPT 패키지·글꼴·레이아웃 검사: 오류 0건, 경고 0건. 네이티브 설명 문구는 Pretendard를 유지했다.
- 가로 글자 너비 추정: 335개 텍스트 상자에서 초과 0건. 실제 화면 검토와 함께 확인했다.
- 그림 비율: PPT의 99개 그림에서 원본 및 크롭 후 비율과 표시 비율을 대조해 허용 오차를 넘는 항목 0건.
- 반응 엔탈피·열량·몰수·실험값 차이 등 11개 계산을 재검산했다. 원본 반응식의 계수·상태·엔탈피 기호와 부호도 자료와 대조했다.
- 25°C의 기화 엔탈피와 100°C의 값을 혼용하지 않았다. 다이아몬드 예시의 +1.9는 완자 문항의 반올림 자료로 계산하고 교과서의 +1.88과 구분했다.

## 검증 범위

실제 PowerPoint 앱 재생, Figma 대조와 사용자 전체 디자인 승인은 수행하거나 추정하지 않았다. 자동 검사의 통과만으로 미감이나 과학적 정확성을 보증하지 않는다. 이번 결과는 검토용 수정본이다.

하네스의 근거 분석·계획·보호 원본 검사(G01·G02·G07)는 실제 재검사에서 통과했다. 승인 증빙이 등록되지 않은 G03~G06·G08·G09는 통과로 기록하지 않았다. 보호 대상 design.md에 새 목록을 덧붙인 건은 원인을 확인하고 이번 작업의 정확한 추가분만 별도 라이브러리로 분리했다. 저장 전 기존 보호 해시와 일치함을 확인했으며 보호 기준 해시는 변경하지 않았다.
