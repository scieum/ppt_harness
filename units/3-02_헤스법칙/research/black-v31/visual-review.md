# v31 시각 검수 · 2026-10-28

검토자: Codex. 사용자 디자인 승인은 대기 중이다.

- 전체 50장 렌더를 10장씩 묶어 확인했다. 제목/본문/표/그림/로고/푸터의 내용 보존 및 검정 배경 대비를 검토했다.
- 생성 계산 패널 15종은 contact-0/6/12에서 수치·연산·첨자를 읽어 대조했다. 엔탈피 H와 Q 등의 수학 기호는 세리프 기울임, 원소와 단위는 정자로 확인했다. 해당되지 않는 전하/상태/반응 방향 검사는 새 부호가 들어가지 않았는지 확인했다.
- 8장의 옛 네이티브 ΔH₂+ΔH₃가 생성 수식과 겹친 것을 제거했다. 8·36·48장의 내용 없는 회색 상자를 제거했다.
- 2장 초록빛은 수평 띠·타원 윤곽 없이 캐릭터 뒤에서 검정으로 사라진다. 인물과 안내판 원본은 유지한다.
- 37·38장은 검정 배경 위 흰색 수식으로 확인했다. 38장의 기존 과밀한 크기를 낮추고 주변 여백을 확보했다.
- 여러 수식은 원본 비율을 유지하고 실제 글자의 추정 높이로 배율을 맞췄다. 측정치는 이미지 박스 높이가 아니다. 자동 판정은 G10 별도 보고서를 따른다.
- 연속 PNG 내보내기에서 일부 앞쪽 글자와 로고가 잘리는 렌더러 상태 문제가 발생했다. 해당 18장을 별도 프로세스에서 재출력했다. 상단 왼쪽 72~96px 구간과 오른쪽 로고 영역의 실제 픽셀 존재도 재확인했다. 원 PPT 객체 좌표는 정상이다.
- 과학 그림의 원본 흰 지면과 내부 검정 글자는 보존했다. 독립 반응식/계산식의 흰색 처리와 구분한다. 표 속 물질명·설명 속 기호는 편집 가능한 텍스트로 남는다.
- PowerPoint 앱에서의 직접 검증이 아닌 artifact-tool 렌더/OOXML 검증이다. 기술 검사 통과는 사용자 디자인 승인과 다르다.
