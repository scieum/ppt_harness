# v20 캐릭터 절제

사용자 요청: 같은 남자 캐릭터가 너무 자주 나오므로 굳이 필요 없는 장표에서는 제거.

12·25·26·29·32·36·40·42장: 안내 인물 8개와 말풍선 제거. 표·수식·체크 목록은 본문 중심으로 이동. 26장의 오개념 주의는 기존 하단 설명에 유지, 42장의 과제 지시는 일반 문구로 보존. 원본 반응식·도입 장면·흑연 삽화·표지/Part 유지. 7·41장의 칠판 대화와 14장의 질문 인물은 역할이 있어 유지.

수정 8장 개별 렌더 확인, 나머지 34장 v19와 픽셀 일치. 표 이동 시 모서리 마스크도 함께 이동. 42장, 파일 구조·기하 검사 통과. 실제 PowerPoint/Figma 검사와 사용자 승인 미완료. 기술 검사로 디자인 승인을 대체하지 않는다.
