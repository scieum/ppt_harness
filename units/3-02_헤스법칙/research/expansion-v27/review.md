# v27 수식 이미지 재생성

사용자 명시 요청으로 37·38장 교재 크롭을 built-in image_gen 신규 투명PNG 두 개로 교체. assets/formation-v27/given.png 및 methods.png, 최종 프롬프트 prompts.json. 편집 가능한 네이티브 텍스트라고 표현하지 않는다.

실제 흰 배경 장표 PNG에서 C/CH4/CO2/H2O 계수·상태·음수부호·첨자와 -890.3kJ를 대조했다. A,B,C를 원래 세 생성 반응으로 지정하고 B+2C−A가 목표 반응임을 확인. H 기울임과 alpha 유지. 생성 이미지 글꼴은 Pretendard 유사체 요청이며 실제 폰트 파일 사용을 보증하지 않는다. 제목과 설명은 기존 Pretendard 유지. 패키지 검사 validation-v27.json. 사용자 디자인 승인·PowerPoint 실사용 확인 별도. 이미지 재생성을 법적 사용 허가 보장으로 기록하지 않는다.
