## 캐릭터와 PART 배경 — 최신 사용자 수정

- 장식용 캐릭터를 제거한 본문은 character_identity를 사유 있는 해당 없음으로 검토한다. 캐릭터의 존재 자체를 통과 조건으로 삼지 않는다.

- 학습 목표는 원본의 큰 연회색 둥근 상자 하나, 번호 원, 문장 위치와 작은 안내 인물의 크기·위치를 따른다. 캐릭터나 상자를 임의로 확대하지 않는다.
- 표지와 PART는 제목·저자·PART·질문·인물 영역의 원본 비율을 따른다. 제목 줄 수와 배치를 임의로 바꾸지 않는다.

- 캐릭터는 등록한 실제 참조 자산을 사용한다. 그림체·얼굴·머리·비율을 임의로 바꾸지 않는다.

## 0. 소단원별 제작 흐름 (우선 적용)

이 프로젝트는 기존 「물에맛.Zip」 수업 PPT의 형식을 계승한다. 아래 규칙은 이후의 일반 규칙과 충돌할 때 우선 적용한다. 사용자의 최신 요청과 승인 범위를 따른다. 분석만 요청한 경우 제작 단계로 넘어가지 않는다.

### 작업 폴더와 자료 관리

- 사용자가 오늘 만들 소단원을 제시하면 프로젝트 루트의 `units/단원번호_소단원명/`에 별도 폴더를 만든다. 이어서 작업하는 소단원은 기존 폴더를 재사용한다.
- 소단원 폴더에 `plan.md`, `research/`, `assets/crops/`, `assets/generated/`, `drafts/`, `renders/`, `final/`을 필요에 따라 만든다. 분석 기록, 크롭, 생성 이미지, 초안, 검수 이미지, 최종 파일을 이 안에 보관한다.
- `textbook-chunjae`와 `etc`의 실제 위치를 먼저 확인한다. 루트에 없으면 `sources/` 등 프로젝트 내부에서 찾는다. 없는 파일을 확인한 것처럼 보고하지 않는다.
- 교과서, 참고 PPT, `sources/` 및 동기화된 원본은 수정·이동·이름 변경·삭제하지 않는다. 파생 자료만 소단원 폴더에 저장한다.

### 반드시 지킬 순서

1. **소단원 확인:** 사용자가 제시한 주제와 수업 범위를 확인한다. 목표 슬라이드 수·수업 시간이 미정이면 제안값을 계획서에 표시한다.
2. **성취기준 확인:** 나무위키나 공식 문서에서 성취기준을 검색한다. 교육부·국가교육과정정보센터 등 공식 원문을 우선하며 나무위키는 탐색·보조 자료로 사용한다. 교육과정 연도, 과목명, 성취기준 코드·문구와 출처 URL을 기록한다. 공식 원문과 대조하지 못한 사항은 미확인으로 표시한다. 2015 개정 화학Ⅱ와 2022 개정 물질과 에너지의 기준을 구분한다.
3. **천재교육 교과서 분석:** `textbook-chunjae`의 물질과 에너지를 주 자료로, 화학Ⅱ를 보조 자료로 분석한다. 관련 본문, 탐구, 그림, 표, 수식, 예제와 정리를 살펴본다. 물질과 에너지의 범위·용어·순서를 기준으로 삼고 화학Ⅱ에서 추가한 내용은 보충·심화로 구분한다.
4. **다른 교과서·완자 비교:** `etc`에서 해당 내용을 찾아 도입, 설명 순서, 예시, 그림, 문제 접근, 오개념 주의점을 비교한다. 채택할 설명과 제외할 내용을 기록한다. 자료가 없으면 누락을 알리고 임의로 내용을 만들어내지 않는다.
5. **계획서 제공과 승인:** 이미지 생성과 PPT 본 제작 전에 소단원 폴더의 `plan.md`를 항상 제공한다. 파일 링크와 페이지 구성 요약을 보여주고 사용자의 승인을 기다린다. 응답이 없다는 이유로 승인 처리하지 않는다.
6. **승인 후 이미지 우선 준비:** 첫 장의 표지 장표 이미지와 필요한 삽화를 먼저 생성한다. 교과서 크롭도 준비하고 이미지를 미리 보여준다. 기존 캐릭터와 단원 색상을 참고한다. 생성 삽화로 정확한 실험 결과·그래프·과학 모형의 근거를 대체하지 않는다. 표지 배경을 생성한 뒤 제목을 편집 가능한 텍스트로 넣어도 된다. 사용자가 별도로 요구하지 않으면 이미지 단계에 추가 승인을 자동으로 만들지 않는다.
7. **내용 구성:** 승인된 계획에 따라 슬라이드와 교과서 그림을 결합하고 발표자 노트와 상세 대본을 작성한다. 범위·페이지 구성에 중대한 변경이 생기면 계획서를 갱신해 변경 부분을 승인받는다. 통상적인 문구·배치는 승인 범위에서 수정한다.
8. **검수와 피그마 검토:** PPT·대본을 검수하고 피그마에 시안을 옮겨 사용자에게 보여준다. 피드백을 반영하고 PPTX·DOCX·피그마의 페이지와 내용을 일치시킨다.

### plan.md 필수 내용

- 소단원명, 교육과정·과목, 수업 목표, 대상, 목표 장수와 예상 시간
- 성취기준 코드·문구·출처와 미확인 사항
- 천재교육 물질과 에너지의 핵심 전개, 화학Ⅱ의 보충 범위
- 다른 교과서·완자와 비교한 결과 및 채택할 설명 방식
- 페이지별 구성 표: 번호, 제목, 핵심 메시지, 설명·활동, 그림·표·수식, 원본 쪽수, 레이아웃, 캐릭터 활용
- 그림 준비 목록: 교과서 크롭 / 기존 자산 / 새 이미지 생성의 구분과 용도
- 디자인 방향, 정확성·오개념 주의점, 제외·심화 내용
- 승인 상태와 변경 이력. 승인 전에는 `승인 대기`로 기록한다.

### 기존 PPT 디자인 계승

- 매 소단원 계획·이미지 준비·PPT 제작 전에 프로젝트 루트의 `design.md`를 읽고 색상·글꼴·레이아웃·캐릭터·교과서 그림 처리 기준을 적용한다. 관찰된 원본 특성과 새 제작 권장값을 구분한다.

- 16:9를 사용한다. Ⅰ. 물질의 세 가지 상태는 분홍 계열, Ⅱ. 용액의 성질은 보라 계열을 기본으로 한다. 다른 단원은 참고 자료나 사용자 설정을 따른다.
- 표지에는 네 캐릭터와 소단원에 맞는 장면, 왼쪽 제목 구성을 사용한다. 표지와 PART 전환에는 기존처럼 색상 배경과 삽화를 허용한다. 아래의 흑백·그라데이션 제한은 일반 본문에 적용한다.
- 본문은 흰 배경, 검정 제목·본문, 회색 보조 문장, 제한적인 단원 강조색을 사용한다. 과학 그림의 색은 유지한다.
- 기본 도입은 표지 → 생활 질문 → 목차 → 학습 목표다. 이후 PART별 관찰·원리·비교·계산·적용을 내용에 맞게 구성한다. 정리는 비교 표, 생활 적용, 계산 또는 도입 질문의 답 등 적절한 형식을 선택한다.
- Pretendard 계열의 굵기 차이와 참고 PPT의 시각적 크기·여백을 기준으로 한다. 상단 PART·소주제, 로고, 하단 출처·페이지 번호 위치를 일관되게 유지한다.
- 네 캐릭터는 표지에서 함께 등장하고 도입·안내·설명에서는 필요에 따라 돌아가며 사용한다. 확인되지 않은 이름·고정 역할을 기존 설정처럼 만들지 않는다. 기존 캐릭터 참조 이미지가 없으면 외형이 같다고 주장하지 않는다.
- 생활 장면, 실험 장치, 입자 모형, 그래프를 연결한다. 같은 그림을 여러 장에서 쓰면 관찰·원인·적용 등 장별 목적을 구분한다.
- 별도 요청이 없으면 슬라이드와 대본은 한국어로 작성하고 필요한 영어 전문용어를 병기한다.

### 교과서 그림 처리

- 해석 가능한 최소 단위로 크롭하며 축·범례·단위·실험 조건·기호·비교 대상과 필요한 캡션을 보존한다. 인접 본문에만 있는 조건은 짧은 설명으로 옮긴다.
- 복잡한 그림은 전체를 먼저 보여주고 부분 확대한다. 비율·비교 배율을 유지하고 원본 라벨을 가리지 않는다.
- 교육과정 연도, 과목, 출판사, 쪽수, 그림 번호와 원본 파일 경로를 기록한다. PDF 페이지와 인쇄 쪽수가 다르면 구분한다.
- 원본 색의 의미와 수치를 유지한다. 재구성한 도식과 생성 삽화는 원본 그림·실험 결과와 구분해 표시한다.

### 피그마와 결과물

- PPT 완성 → 피그마 시안 반영 → 사용자 확인 → 수정의 흐름을 따른다.
- 사용자가 제공한 피그마 파일을 사용한다. 대상 링크가 없으면 피그마 반영 시점에 확인하고 그전까지 가능한 제작·검수를 진행한다.
- 피그마 작업 전에 해당 Figma 스킬을 읽는다. 텍스트와 기본 배치는 편집 가능한 디자인 레이어로 옮기며 교과서 크롭과 생성 삽화는 이미지로 유지한다. 편집 가능 범위의 제한을 알린다.
- 슬라이드 번호·제목으로 프레임을 구분하고 그림 누락, 글꼴 대체, 줄바꿈과 배치를 검수한다. 실제 반영하지 않고 완료했다고 보고하지 않는다.
- 최종 결과물은 PPTX, 슬라이드별 상세 발표 대본 DOCX, 피그마 시안 링크다. 분석·계획 단계에는 해당 보고나 plan.md만 제공한다.


## 1. 발표자료 구성

- 전체 분량은 설정한 목표 슬라이드 수에 맞춰 구성해줘.
- 원본 자료의 논리와 전개 순서를 최대한 충실하게 반영해줘.
- 기본적으로 문제 또는 목적 → 필요한 배경지식 → 핵심 아이디어 → 구체적인 방법·시스템·과정 → 수식 또는 분석 → 결과와 근거 → 한계와 함의 순서로 전개해줘.
- 원본 자료의 성격상 맞지 않는 단계는 억지로 넣지 말고 자연스럽게 조정해줘.
- 각 페이지는 하나의 핵심 메시지만 전달하도록 구성해줘.
- 슬라이드 제목만 순서대로 읽어도 전체 발표의 논리적 흐름을 이해할 수 있게 해줘.
- 원본 자료의 중요한 Figure, Chart, Table, Diagram, Algorithm, 수식, 사례는 빠뜨리지 말고 포함해줘.
- 원본 자료에 있는 내용과 수치를 정확히 사용하고, 자료에 없는 주장이나 수치를 임의로 만들지 마.
- 제작자의 해석이나 추가 설명이 필요한 경우 원본의 주장과 명확하게 구분해줘.
- Figure나 Chart를 넣을 때 축 제목, 범례, 단위, 캡션이 잘리지 않도록 전체가 보이게 넣어줘.
- 원본 시각자료가 복잡하면 필요한 부분을 강조하거나 다시 구성해도 되지만, 원본의 의미가 달라지지 않게 해줘.
- 시각자료만 넣지 말고, 슬라이드 안에 “이 자료에서 무엇을 봐야 하는지”를 짧게 적어줘.
- 수식은 결과만 넣지 말고, 주요 기호의 뜻과 수식이 왜 그렇게 나오는지 설명할 수 있게 구성해줘.
- Algorithm이나 절차는 원문만 붙이지 말고, 가능하면 동작을 보여주는 그림이나 단계별 흐름도를 함께 넣어줘.
- 원본에 수식이나 Algorithm이 없는 경우에는 이 항목을 억지로 추가하지 마.
- 발표 시간 안에 설명하기 어려운 부가 내용은 핵심 슬라이드에 억지로 넣지 말고 대본이나 부록으로 분리해줘.

## 2. 디자인

전체적으로 흑백 중심의 미니멀한 디자인으로 만들어줘.

- 화면 비율: 16:9
- 배경: 흰색
- 제목과 본문: 검정 또는 진한 회색
- 보조 설명: 중간 회색
- 강조 색상: 원본 Figure나 Chart를 이해하는 데 필요한 색상만 제한적으로 사용
- 그라데이션, 장식용 아이콘, 화려한 도형, 불필요한 배경 이미지는 사용하지 마.
- 페이지마다 동일한 장식적 구성을 반복하지 말고, 내용을 가장 잘 설명할 수 있는 레이아웃을 선택해줘.
- 참고 PPT가 있다면 색상, 여백, 글꼴과 전반적인 분위기는 비슷하게 유지하되, 사용자가 지정한 레퍼런스의 구성·위치·비율을 그대로 따른다. 임의 재배치는 금지한다.
- Figure 중심 페이지, 수식 중심 페이지, 과정 설명 페이지, 비교 페이지 등 내용에 맞게 레이아웃을 달리해줘.
- 제목, 본문, Figure 사이의 간격을 충분히 확보해줘.
- Figure가 너무 작아지지 않도록 하고, Figure와 설명문의 비율을 균형 있게 맞춰줘.
- 슬라이드 본문은 너무 비어 보이지 않게 하되, 긴 문단을 그대로 넣지는 마.
- 한 페이지에 핵심 설명을 약 3~5개 넣고, 자세한 내용은 발표 대본으로 분리해줘.
- 단, 하나의 큰 Figure나 수식이 핵심인 페이지는 설명 수를 억지로 채우지 않아도 돼.
- 모든 페이지에서 제목 위치, 페이지 번호, 여백, 글꼴 크기를 일관되게 유지해줘.
- 슬라이드 하단에는 원본 자료의 페이지, Figure 번호 또는 출처를 작게 표시해줘.

## 3. 글꼴과 크기

- 제목: 깔끔한 산세리프 계열, 약 26~32pt
- 핵심 메시지: 20~24pt
- 본문: 16~20pt
- Figure 캡션과 출처: 10~12pt
- 너무 작은 글씨로 많은 내용을 억지로 넣지 마.
- 수식은 발표 화면에서 바로 읽을 수 있을 정도로 크게 넣어줘.
- 표 안의 글자가 너무 작아진다면 표 전체를 한 장에 넣지 말고 여러 장으로 나누거나 핵심 행과 열을 강조해줘.
- 발표자가 설명해야 하는 Figure의 축, 범례와 주요 숫자는 화면에서 읽을 수 있어야 해.

## 4. 슬라이드 언어

- 슬라이드와 발표 대본은 상단의 언어 설정을 따라줘.
- 별도 설정이 없으면 슬라이드의 제목과 핵심 문장은 한국어로 작성하고 필요한 영어 전문용어를 병기해줘.
- Figure 안의 원문 표기와 고유 용어는 원래 언어를 유지해줘.
- 별도 설정이 없으면 발표 대본과 상세 설명은 한국어로 작성해줘.
- 영어 전문용어가 처음 등장하면 한국어로 의미를 설명해줘.
- 같은 개념을 여러 표현으로 바꾸지 말고, 발표 전체에서 용어를 일관되게 사용해줘.

## 5. 발표 대본

발표자의 배경지식이 충분하지 않더라도 내용을 이해하고 발표할 수 있도록 별도의 DOCX 발표 대본을 만들어줘.

발표 대본은 PPT의 내용을 요약하는 부록이 아니라, 발표자가 자료를 실제로 이해하고 청중에게 설명할 수 있도록 만든 완성된 발표 원고여야 해.

각 슬라이드별로 필요한 항목을 포함해줘.

1. 먼저 알아야 할 배경지식
2. 실제로 읽을 수 있는 자연스러운 발표 대본
3. 화면에서 먼저 가리킬 부분
4. Figure나 Chart를 가리키는 순서
5. 축, 범례, 색상, 화살표와 박스의 의미
6. 수식에 등장하는 기호의 뜻
7. 수식이 만들어지는 단계별 과정
8. Algorithm이나 프로세스의 입력, 반복 과정, 조건과 출력
9. 헷갈리기 쉬운 점
10. 이 내용이나 결과가 중요한 이유
11. 다음 슬라이드로 넘어가는 연결 문장

모든 슬라이드에 위 항목을 기계적으로 전부 넣지는 말고, 해당 슬라이드를 설명하는 데 필요한 항목만 사용해줘.

발표 대본은 원본 자료를 단순히 번역하거나 슬라이드의 문장을 그대로 읽는 형태로 작성하지 마. 발표자가 내용을 실제로 이해하고 화면을 가리키며 설명하는 것처럼 자연스럽게 작성해줘. 발표자의 배경지식이 부족하더라도 대본을 순서대로 읽으면 개념, 문제, 방법과 결과를 이해할 수 있어야 해.

설명이 지나치게 길어지지 않도록 발표 시간에 맞춰 슬라이드별 분량을 조절해줘. 중요한 Figure, 수식, Algorithm이 있는 슬라이드는 조금 더 자세히 설명하고, 전환이나 요약 슬라이드는 짧게 작성해줘.

수식이 있는 경우 다음 방식으로 설명해줘.

- 먼저 이 수식이 무엇을 계산하거나 표현하는지 설명
- 각 기호가 무엇을 의미하는지 설명
- 앞 항과 뒤 항이 각각 어떤 의미인지 설명
- 어떤 기본식이나 가정에서 출발했는지 설명
- 값을 하나씩 대입해 최종식이 나오는 과정을 설명
- 가능하면 숫자를 사용한 간단한 예시 제공
- 이 수식이 Figure, 결과 또는 설계 결정과 어떻게 연결되는지 설명

Algorithm이나 절차가 있는 경우 다음 방식으로 설명해줘.

- 이 알고리즘 또는 절차가 필요한 이유
- 입력값이나 시작 조건의 의미
- 각 단계나 반복문이 처리하는 대상
- 조건식이나 의사결정 기준이 필요한 이유
- 후보나 결과를 평가하는 기준
- 최종 출력값이나 도달 상태
- 가능하면 실제 숫자나 작은 사례를 이용한 예시
- 관련 Figure, 시스템 구조 또는 실제 결과와 연결한 설명

수식이나 Algorithm이 없는 일반적인 자료에서는 같은 원칙을 프로세스, 의사결정 구조, 분석 방법 또는 업무 흐름 설명에 적용해줘.

## 6. Figure와 시각자료 처리

- 원본 자료에 포함된 Figure, Chart, Table과 Diagram을 우선 사용해줘.
- 축, 범례, 단위와 캡션이 잘리지 않도록 crop을 최소화해줘.
- 원본 시각자료가 발표에 적합하지 않으면 제작자의 공식 발표자료, 공식 보고서 또는 공식 문서에서 더 이해하기 쉬운 버전을 찾아 사용해도 돼.
- 외부 시각자료를 사용할 경우 원저자, 기관, 기업 또는 공식 문서를 우선해줘.
- 출처를 슬라이드 하단과 발표 대본에 기록해줘.
- 원본 시각자료가 너무 복잡하면 그 위에 많은 내용을 덮지 말고, 옆에 번호와 짧은 설명을 배치해줘.
- 필요한 경우 원본의 의미와 수치를 유지하면서 설명용 도식으로 다시 그려도 돼.
- 다시 그린 도식은 원본 자료와 혼동되지 않도록 ‘adapted from’, ‘simplified view’ 또는 이에 해당하는 표현으로 표시해줘.
- 설명을 위해 새 그림을 만들었을 때는 원본에 실제로 존재하는 결과처럼 보이게 하지 마.
- 시각자료가 없는 내용은 긴 글로 채우기보다 관계, 순서 또는 비교를 보여주는 간단한 도식으로 표현해줘.

## 7. 내용 정확성

- 원본 자료의 핵심 주장, 조건, 수치와 결론을 정확하게 유지해줘.
- 원본 자료에 없는 인과관계를 새로 만들어내지 마.
- 수치나 성능 결과를 제시할 때는 비교 대상, 조건, 단위와 기준을 함께 표시해줘.
- 특정 조건에서만 성립하는 결과를 일반적인 결론처럼 표현하지 마.
- 원본 자료의 한계, 적용 조건과 반례가 있다면 함께 포함해줘.
- 외부 자료를 추가할 때는 원본 자료와 외부 자료의 내용을 명확히 구분해줘.
- 내용이 불확실하거나 해석이 여러 가지라면 임의로 확정하지 말고 대본에 주의점으로 표시해줘.

## 8. 최종 검수

완성 후 PPT와 대본을 실제로 열거나 렌더링해서 다음을 반드시 확인해줘.

- Figure와 Chart의 축, 범례, 단위가 잘리지 않았는지
- 이미지가 흐리거나 누락되지 않았는지
- 이미지의 가로세로 비율이 깨지지 않았는지
- 수식이 슬라이드에서 읽을 수 있는 크기인지
- 제목, 본문, Figure와 페이지 번호가 겹치지 않는지
- 표 안의 글자가 지나치게 작지 않은지
- 발표 대본의 슬라이드 번호가 PPT와 일치하는지
- 모든 슬라이드에 발표자 노트와 출처가 있는지
- 원본 자료의 핵심 Figure, 수식, Algorithm, 결과 또는 사례가 빠지지 않았는지
- 원본의 주장과 슬라이드에 적힌 수치가 일치하는지
- 비슷한 내용이 여러 슬라이드에서 불필요하게 반복되지 않는지
- 설정한 발표 시간 안에 전체 대본을 발표할 수 있는지
- PPTX와 DOCX 파일이 실제로 정상적으로 열리는지

문제가 발견되면 최종 파일을 전달하기 전에 먼저 수정하고 다시 검수해줘.
