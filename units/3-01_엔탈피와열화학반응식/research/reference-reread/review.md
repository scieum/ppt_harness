## 원본에서 확인한 구성과 이전 제작의 오류

### 1. 표에는 서로 다른 두 가지 역할이 있다

- 물의 구조 16장, 삼투 현상 14·26장, 분자 간 상호 작용 28장, 고체 13·14·27장: 짙은 회색의 큰 둥근 바탕에 흰 글자. 머리행 아래 밝은 가로선, 본문은 옅은 가로선. 세로 격자와 교대 회색 셀을 쓰지 않는다. 첫 열과 수치 열의 정렬·글자 굵기도 구별된다.
- 물의 여러 가지 성질 14장: 교과서 비열 표의 선·색·서체를 보존한 채 물에 해당하는 칸만 외곽선과 곡선 화살표로 강조한다.
- 끓는점 오름과 어는점 내림 18·29장: 교과서 상수 표를 왼쪽에 두고 오른쪽 연회색 둥근 영역에 번호 설명을 둔다.
- 분자 간 상호 작용 17장: 교과서 쌍극자 모멘트 표를 중앙에 두고 아래 두 문장으로 해석한다.
- 이전 전체본의 회색 격자 표 일괄 적용은 이 구별을 지웠다. 원본 자료 표와 교사가 정리한 비교 표를 구분해야 한다.

### 2. 교과서 그림 자체가 설명의 중심이다

- 물의 구조 14장, 물의 여러 가지 성질 9·10·17장, 액체 13·14·16·17·21장, 분자 간 상호 작용 24·36장: 원본 그래프의 축·범례·선·표기까지 보존하고 필요한 해설을 옆이나 아래에 붙인다.
- 증기 압력 내림 6~8장, 삼투 현상 7~12장, 고체 17·19장: 실험 장치·입자 모형·확대도·변화 단계를 원본 관계대로 보여 준다.
- 원본 그림이 있는데도 자체 단순 그래프를 새로 그린 것은 잘못된 제작 선택이다. 색을 맞춘 자체 그래프는 원본 그림을 대체할 근거가 되지 않는다.
- 원본의 작은 글씨가 흐리면 먼저 원본 PDF/내장 이미지에서 고해상도로 추출한다. 확대된 저해상도 캡처로 해결하지 않는다.

### 3. 장표를 넘기는 흐름도 레퍼런스의 일부다

- 혼합 기체의 부분 압력 6→7→8장: 세 용기를 먼저 보여 준 다음 비교할 용기만 확대하고 질문을 바꾼다. 소주제 번호는 01로 유지한다.
- 물의 여러 가지 성질 9→10장, 액체 13→14장: 전체 그래프를 제시한 뒤 같은 자료를 확대·해설한다.
- 고체 26→27장: 네 종류의 결정 모형으로 비교한 후 표로 정리한다.
- 페이지마다 새로운 번호와 새로운 레이아웃을 붙이는 방식은 이 수업 흐름을 놓친다. 번호는 소주제 단위이며 슬라이드 번호가 아니다.

### 4. 본문 배치는 한 종류로 통일되지 않는다

- 중앙 핵심 문장 → 바로 아래 회색 보조 문장 → 큰 원본 그림의 구성이 반복된다.
- 설명이 긴 장표는 왼쪽 큰 제목·번호 설명 + 오른쪽 원본 그림을 사용한다. 분자 간 상호 작용 8·23·34·35장, 고체 16·18·21·23장이 구체적인 예다.
- 번호 설명은 연회색 둥근 판 안에 검정 글자와 작은 회색 원 번호를 넣거나, 흰 바탕에 직접 놓는다. 긴 결론은 그림 아래 짙은 회색 막대에 흰 글씨로 둔다. 모든 설명을 동일한 박스로 바꾸지 않는다.
- 핵심 개념의 포인트색, 중요 어구의 밑줄, 얇은 곡선 화살표는 의미가 있을 때 쓴다. 모든 제목을 검정 한 줄로 통일하지 않는다.
- 번호 원은 본문 글자에 맞는 보조 요소다. 원 때문에 줄 높이와 여백을 크게 늘리지 않는다.

### 5. 사진과 설명은 카드 안에서 한 덩어리다

- 끓는점 오름과 어는점 내림 23·34장, 혼합 기체의 부분 압력 23·24장: 짙은 둥근 카드 안에 사진, 흰 밑줄 제목, 짧은 흰 설명이 이어진다.
- 사진 밑에 별도의 작은 출처 캡션을 덧붙이지 않는다. 출처는 노트에 기록한다. 과학 도식 내부의 축·원자·기호는 사진 캡션과 구분해 보존한다.
- 그림을 크게 넣고 설명을 화면 맨 아래로 밀어내지 않는다. 설명 상자 공간을 먼저 확보하고 그림을 맞춘다.

### 6. 수식과 반응식

- 혼합 기체의 부분 압력 15~20장은 원본 수식의 분수·첨자·수학 서체를 보존하고, 원·화살표로 특정 항만 설명한다.
- 사용자 최신 지시: 화학 반응식은 교과서 원본을 최대한 그대로 사용한다. 해당 반응식이 없을 때 직접 제작한다. 네이티브 텍스트로 만들기 편하다는 이유만으로 원본을 일괄 재작성하지 않는다.
- 직접 제작하는 경우 계수·원소 기호·괄호는 정자, 상태 문자 s/l/g/aq만 기울임체. 계수·상태·화살표·ΔH 값·부호·단위까지 원문 대조한다.
- 원본에 상태 서식 보정이 필요하면 해당 부분만 최소한으로 보정한다. 수식 전부를 흐린 누끼 이미지로 바꾸지 않는다.

## 사용자 정정으로 우선하는 기준

- 모든 표기는 Part. 옛 표지의 PART를 다시 복원하지 않는다.
- Pretendard 실제 로딩 확인. 미리캔버스 사용자 값: Part 28.5 Bold, 번호·소주제 36.6 Bold, 검정 핵심 57.3 Bold, 회색 보조 27.3 Bold, 긴 회색 상자 안 흰 글자 33.4 Medium. 1920×1080 작업 환산은 각각 38/48.8/76.4/36.4/44.5px.

- T셀파는 첫 표지에만. 옛 레퍼런스의 반복 로고를 그대로 복원하지 않는다.
- 수정 전에 각 장표에 원본 소재와 참고 레이아웃 장표를 연결한다. 사용자에게 거부된 전체본 자체를 새 기준으로 삼지 않는다.
