# 물질과 에너지 3-01 · 엔탈피와 열화학 반응식 구성 계획

작성: 2026-10-19 · 검토용 계획안 · 전체 31장 / 50분 제안

## 1. 기준과 이번 산출물

첫 번째 소단원 전체를 PART 1~3으로 구성한다. 기준은 직전 수정 시안의 최종 파일 **cover-lower-three-v10-20261019(V10)**이다. V7 이후 수정 사항까지 반영한다. 기존 31장 계획의 내용 범위를 유지하면서 수업 순서와 장표별 자료·삽화 용도를 구체화한 문서다. 이 문서에 적힌 신규 삽화는 제작 계획이며 아직 생성하지 않았다. 시간은 교사 설명·짧은 발문·자료 해석 중심의 제안값이다. 실제 모둠 실험을 포함하면 별도 차시가 필요하다.

현재 채팅의 작업 경로에는 기존 프로젝트가 없어, 기존 OneDrive 프로젝트를 읽기 전용으로 참고하고 이 파일을 요청한 작업 경로에 작성했다. 과거 계획의 승인 기록을 이 개정 계획의 승인으로 옮겨 적지 않는다.

### V10에서 유지할 디자인

- 표지: 현재 교실 손난로 장면·네 캐릭터·녹색 그라데이션·두 줄 흰 제목·저자·로고 유지. 제목 상단 y=269.3(1920×1080 기준)으로 마지막 위치 수정 반영. 녹색 #0C7D08, 강조 연두 #9FFF68.
- 목차: 허들링 레퍼런스의 검정 화살표형 PART 블록 3개, 기존 위치·간격 유지. Part 0을 추가 카드로 만들지 않는다.
- 목표: 큰 연회색 상자와 번호 원·작은 안내 인물 유지. 번호·문장 그룹은 원래 가로 위치와 왼쪽 정렬을 유지하고 세로만 중앙 정렬.
- PART: 현재 표지 장면에 검정 51% 덮개. 제목·글자에는 덮개 불투명도를 적용하지 않는다. 부제는 해당 이론을 궁금하게 만드는 한 줄 질문으로 쓰며 정의식·항목을 나열하지 않는다.
- 도입: 회색 ‘Part 0 동기 유발’, 검정 소주제 ‘손난로와 열’, 큰 한 줄 질문, 아래 회색 설명, 하단 학생 1인 투명 PNG. 실제 수업에서는 PART 1보다 먼저 제시한다.
- 본문: 흰 바탕, 회색 PART명 → 소주제 번호와 검정 주제명 → 핵심 문장 → 회색 보조 설명 → 큰 과학 그림 순서. 수식·계산·큰 입자 도식에는 장식용 캐릭터를 넣지 않는다. 번호 원·회색 계산 단계 띠·비교표·부분 확대는 원본 용도에 맞춰 쓴다.
- T셀파는 첫 표지에만 원본 크기·위치로 배치. 사이음 로고와 저작권은 해당 원본 기준. 표지의 생성형 AI 안내 문구 유지.

## 2. 학습 목표와 범위

1. 엔탈피의 의미를 알고, 엔탈피를 이용하여 열화학 반응식을 표현한다.
2. 같은 양 또는 같은 질량이라는 기준을 정해 연료의 효율성을 비교한다.
3. 결합의 해리·형성에 따른 에너지 출입으로 반응 엔탈피를 설명한다.

주 성취기준은 [12물에03-01]. 천재교육 2022 개정 『물질과 에너지』 74~81쪽을 우선한다. 엔탈피는 일정한 압력에서의 열 출입과 변화량으로 설명한다. H=U+pV 유도, 압력-부피 일, 표준 생성 엔탈피 계산, 헤스 법칙, 엔트로피·자발성 판정은 이 소단원에서 제외한다. 대단원명에 ‘자발성’이 있더라도 발열 여부만으로 자발성을 판단하게 하지 않는다.

열량계(12장)는 교과서 77쪽 ‘좀 더 자세히’에 근거한 보충이다. 용액의 온도 변화와 반응의 열 출입을 연결하는 수준으로 제한하며 장치 보정·정밀 열용량 계산을 추가하지 않는다.

## 8. 과학 내용·계산 검토 기준

- 발열은 반응계의 ΔH<0이며 주위의 온도는 보통 상승한다. ‘온도가 높아지므로 엔탈피가 증가한다’처럼 반응계와 주위를 섞지 않는다. 엔탈피 그래프의 가로축은 반응 진행이며 시간이나 활성화 에너지 그래프로 바꾸지 않는다.
- 열화학 반응식에는 상태·계수·ΔH가 함께 필요하다. 원본 수식 크롭은 첨자·음수 부호까지 포함한다. 크롭 이미지를 편집 가능한 수식이라고 표현하지 않는다.
- 12장: Q용액=cmΔt, 열 손실 등을 무시할 때 q반응=−Q용액. 일정 압력에서 해당 반응량의 ΔH와 연결한다. 몰당 값은 반응량으로 나누어야 하며 Q의 단위는 비열 단위와 일치시킨다.
- 16~19장: ‘방출열의 크기’ 표에서는 양수 kJ/mol·kJ/g를 사용하고 ΔH와 구분한다. 교과서 78쪽의 양수 ‘연소 엔탈피’ 항목은 방출열 크기를 나타내는 표임을 설명한다. 뷰테인 −5754 kJ는 2 mol 반응 기준, 수소 −571.6 kJ는 2 mol 반응 기준이다.

- ‘수소가 가장 크다’는 위 네 연료·동일 질량·교과서 반응 조건의 비교에 한정한다. 연소열만으로 실제 장치 효율·저장 편의·생산 과정의 환경성을 결론내리지 않는다.
- 23~25장: 해리는 흡열, 형성은 발열. 기체 결합 1 mol 기준이고 결합 에너지 자체는 양수다. 실제 반응이 반드시 모든 원자의 완전 분리 단계를 거친다는 뜻으로 26장의 계산 모형을 설명하지 않는다.
- 26~28장: 반응식 2H₂(g)+O₂(g)→2H₂O(g), H 원자 4개·O 원자 2개 보존. H–H 2개, O=O 1개 해리 / O–H 4개 형성. 2×436+498−4×460=−470 kJ는 이 반응식 기준 근삿값이며 1 mol 물 기준은 −235 kJ/mol에 해당한다. 액체 물 생성의 −571.6 kJ와 혼용하지 않는다.
- 31장 HF 출구 문항: H₂(g)+F₂(g)→2HF(g), ΔH≈436+159−2×570=−545 kJ. 답은 제시 후 공개하고 기체 상태·결합 수·부호를 함께 확인한다.
